# Problem Solving & Safety Protocol

1. Before attempting to fix any issue or error, verify if tests or the application are currently passing/working.
2. Attempt the fix by making the necessary changes.
3. Test or verify if the proposed solution actually fixes the issue.
4. **CRITICAL REVERT RULE:** If the attempt fails or does NOT resolve the problem:
   - Immediately revert the modified files back to their original state before trying a new approach.
   - Do not leave non-working experimental code behind.
